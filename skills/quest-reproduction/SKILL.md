---
name: quest-reproduction
description: Reproduce a Lives of Night City quest transition under the active Vortex deployment using an authenticated alternate-start save, ordered quest milestones, and private gameplay evidence.
---

Run the pilot's `profile` preflight and inspect `saves` before choosing a route. The Vortex profile describes the intended order. The manifest and deployed files describe the game installation. Stray NCL archives and a generic modded-save flag can survive a profile change. Use a slot marked `verified` by the NCL class marker check. Confirm the expected role or alternate-start state after loading. Keep the user's active profile and deployment intact. If the profile does not deploy NCL, record the mismatch and stop the gameplay attempt.

Work backward from the reported transition using the deployed mod version, relevant quest graph, and ticket details. Identify which choices, callbacks, journal transitions and travel boundaries can affect this outcome. Plan them in chronological order in each case's `milestones` array. Include a distinguishable observation for the initial save state and the last state immediately before the trigger. For a negative case include the specific prerequisite that must still be absent and how to observe its absence.

When the target has no nearby save, search the journal paths of known predecessor objectives with `saves QUEST_FRAGMENT`. Check the complete inventory for untracked jobs and alternate starting histories. Verify eligibility in the loaded game's journal and relevant mod state before spending time on the route. A slot that has already committed the opposite choice needs an earlier branch point. If a long route stalls, report the last confirmed milestone, the missing condition and the evidence collected there. Only credit quest history actually replayed or independently confirmed. Starting a new character and building reusable branch saves are separate from the pilot's existing manual-slot launch.

Drive forward from an ordinary verified save. Use `observe` to capture the actual tracked objective, position and named quest facts through WkMCP on either side of the trigger. Verify the individual save row's class in the Load Game menu; a group's heading can display its vanilla lifepath even when the selected row displays a tabletop class. If the character owns a vehicle, the game's AutoDrive can follow a tracked objective across the city. Confirm the route and destination on the HUD and complete the approach and interaction with player controls. Use the current installation's fact names and meanings. Record each reached milestone with `milestone`, a route clip, and the observation. When neither the screen nor instrumentation distinguishes the required branch, report inconclusive.

Exercise the causal sequence with gameplay inputs. A teleport across a volume, direct fact write, spawned caller or forced journal update can bypass the event the ticket is about. A shortcut is usable only for a segment already shown equivalent on this deployment. Keep experiments with fabricated state separate from reproduction evidence. After any reload, confirm that prior quest conditions still hold before triggering the case.
